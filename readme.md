# 🧠 Med-RAG-BIOT: LLMOps Project for Intelligent Question Generation

## 🚀 Overview
**Med-RAG-BIOT** is an end-to-end **LLMOps** and **AIOps** project designed to demonstrate **production-grade deployment** of Large Language Model (LLM) applications.  
This project focuses on **automated question generation** (MCQs, fill-in-the-blanks, etc.) using **Retrieval-Augmented Generation (RAG)** integrated with **Vector Databases**, **Cloud**, and **Monitoring pipelines**.

It is designed as part of the **LLMOps & AIOps Bootcamp**, showcasing how to **build, deploy, monitor, and scale** an AI application using modern DevOps and MLOps tools.

---

## 🧩 Project Objective
Develop an AI-driven question generator that:
- Takes **user topic input**
- Generates **MCQ / Fill-in-the-blank questions**
- Evaluates user responses
- Stores results and analytics
- Deployed using **CI/CD pipelines, containerization, orchestration**, and **cloud infrastructure**

---

## ⚙️ Tech Stack

| Layer | Tool/Tech | Purpose |
|-------|------------|---------|
| **LLM Backend** | OpenAI / HuggingFace Models | Question generation |
| **Retrieval** | **Vector DB (Chroma / Pinecone / Weaviate)** | Context retrieval for RAG |
| **API Backend** | FastAPI / Flask | Application logic & endpoints |
| **Containerization** | Docker | Packaging the app |
| **CI/CD** | Jenkins | Continuous integration & deployment |
| **Orchestration** | Kubernetes (K8s) | Scaling and service management |
| **Monitoring** | Prometheus + Grafana | Resource and performance monitoring |
| **Cloud** | AWS / GCP | Hosting and data storage |
| **Data Storage** | PostgreSQL / S3 Bucket | Result and data persistence |
